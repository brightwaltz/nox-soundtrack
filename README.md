# Nox — Original Soundtrack

イマーシブ作品『Nox』（監督 ナカダリオ、第83回ヴェネチア国際映画祭 Venice Immersive 選出）の音楽（brightwaltz）を聴くためのページです。

https://brightwaltz.github.io/nox-soundtrack/

- 音源は支援者の方への先行公開です。`audio/*.bin` は AES-256-GCM で暗号化してあり、お知らせのリンクから開いたときだけブラウザの中で復号して再生します。
- 3D の水は three.js（`js/vendor/`、MIT License）で描いています。WebXR に対応した機器では「VR で聴く」が出ます。
- キービジュアルは監督の許諾を得て使っています。画像・音源の転載と再配布はご遠慮ください。

作り方と検査の手順は `tools/README.md` にあります。
